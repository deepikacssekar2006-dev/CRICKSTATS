# CRICKSTATS

## Cricket Player Performance Tracking Application

CRICKSTATS is a Salesforce-based application for managing and displaying
cricket player performance information.

## Features

- Player management
- Team-based player filtering
- Match Performance management
- Player statistics
- Total Runs
- Average Score
- Matches Played
- Number of 50s
- Number of 100s
- Batting Style
- Bowling Style
- Player information display using Salesforce Flow

## Salesforce Components

- Player Object
- Match Performance Object
- Roll-Up Summary Fields
- Formula Fields
- Screen Flow
- Lightning App
- Home Page
